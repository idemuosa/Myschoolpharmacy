Josiah POS Command Sheet

Scan these codes to control the system without touching your mouse or keyboard.

1. Focus Search / Scan Mode

Clears search and prepares for next item

2. Cycle Payment Method

Switch Cash / POS / Transfer

3. Clear Entire Cart

Empty all items and start over

4. FINALIZE & PRINT RECEIPT

COMPLETE TRANSACTION

PRO TIP: Print this sheet and tape it next to your laptop. When you're done scanning items, just scan the "Finalize & Print" code to trigger the thermal printer instantly!
