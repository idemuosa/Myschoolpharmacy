# Railway Deployment Guide 🚀

The project has been optimized for **Railway.app**. Follow these steps to deploy your 3-tier architecture.

## 1. Create a Railway Project
1. Log in to [Railway.app](https://railway.app/).
2. Click **New Project** > **Deploy from GitHub repo**.
3. Select your repository (`Myschoolpharmacy`).

## 2. Define the Services (Multiservice setup)
Since this is a monorepo, you need to create **three separate services** on Railway from the same repository:

### Service A: Django API (The Brains)
- **Service Name:** `pharmacy-api`
- **Root Directory:** `backend`
- **Railway Action:** Go to **Settings** > **Root Directory** and set it to `/backend`.
- **Environment Variables:**
  - `DEBUG`: `False`
  - `SECRET_KEY`: (Generate a long random string)
  - `DATABASE_URL`: (Link to your Railway Postgres service)
  - `REDIS_URL`: (Link to your Railway Redis service)

### Service B: Node.js Sockets (The Real-time Hub)
- **Service Name:** `pharmacy-socket`
- **Root Directory:** `node_backend`
- **Railway Action:** Set **Root Directory** to `/node_backend`.
- **Environment Variables:**
  - `DATABASE_URL`: (Link to same Postgres)
  - `ACCESS_TOKEN_SECRET`: (Generate random string)
  - `PORT`: `4000`

### Service C: React Frontend (The Face)
- **Service Name:** `pharmacy-frontend`
- **Root Directory:** `pharmacy`
- **Railway Action:** Set **Root Directory** to `/pharmacy`.
- **Environment Variables:**
  - `VITE_API_URL`: (The URL of your `pharmacy-api` service)
  - `VITE_SOCKET_URL`: (The URL of your `pharmacy-socket` service)

## 3. Add Infrastructure
Inside your Railway project, click **New** > **Database** to add:
1. **PostgreSQL**
2. **Redis**

## 4. Why Railway + Docker is Better?
- **Zero Config:** Railway reads your `Dockerfile` automatically.
- **No Sleep:** Unlike Render, your API stays awake and fast.
- **Cost Effective:** You only pay for what you use.
